Plug in your badge

Badge Studio talks to the badge over USB, straight from the browser: install and remove apps, change its settings, take screenshots and open a MicroPython console. Nothing to install.

Connect it with a USB-C cable, then press Connect badge and pick it in the list.

        Extensions

        Modified versions of the badge's own apps, and the apps that ship in /system in Akiyo974/badger: Badge with QR codes and NFC, Contacts with link checks, Radar, Duck Maze, the menu with the CUSTOM band and this home screen layout… Built-in apps live in /system, which only the USB drive can change: the badge switches to USB drive mode, you pick the apps folder of its BADGER drive once, and the current version is backed up on the drive before it is replaced, so it can be restored.

        Repair

        A folder went missing, an app no longer starts, the menu crashes? Repair compares every file of the badge's BADGER drive (/system) with a healthy copy and puts back the ones that are missing or different. Files are only added or replaced, never deleted. Your settings (secrets.py) and the apps you installed from the store (in /apps, another part of the memory) are never touched.

        1. Press Switch to USB drive mode with the badge connected. If the badge no longer starts, double-tap its RESET button instead: it shows up as a USB drive named BADGER.
        2. Press Pick the BADGER drive and choose the drive itself (the folder that holds main.py and apps).
        3. Read the comparison, then press Put back missing files (safe: your own changes stay) or Repair all (different files are backed up, then replaced).
        4. Press Restart the badge.

        Pick the BADGER drive to compare it.

        Settings

        The badge's secrets.py. Changes are saved on the badge and apply after a reboot.

        Settings marked 🔒 are set in /system/secrets.py on the USB drive, which takes priority: change those in USB drive mode, or with the badge's Settings app.
